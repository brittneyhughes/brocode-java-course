## Running a Project

Requirements:

- Java Development Kit (JDK) compatible with the project's `pom.xml`
- IntelliJ IDEA or another Java development environment

To run a project in IntelliJ IDEA:

1. Open the individual project folder under `projects/`.
2. Allow IntelliJ to load the Maven configuration.
3. Select the appropriate JDK.
4. Run the project's main class.

See each project's README for instructions and any additional requirements.
