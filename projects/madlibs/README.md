# Mad Libs: The Great Zoo Escape
A Java console game that turns your words into a silly zoo escape story.

## How to Play
1. Run the program.
2. Enter the requested nouns, verbs, and adjectives.
3. Read your custom story
4. Enter `yes` to play another round, or `no` to exit.

Note: Use base-form verbs such as `run`, `sing`, or `jump`.

## Requirements
- Java Development Kit (JDK)
- A terminal or Java IDE

## Running the Game
Open the project in your Java IDE and run `src/main/java/com/brittneyhughes/madlibs/Main.java`.

## Sample Output
```text
Every Tuesday, Bowie the purple cat tried to escape from the zoo.
The plan was always the same: run until the zookeeper got distracted,
then sing straight through the front gate.
```
