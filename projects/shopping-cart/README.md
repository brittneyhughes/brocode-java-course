# Shopping Cart

A Java console program that calculates the total cost of an item based on its price and quantity.

## How to Use

1. Run the program.
2. Enter the item you want to buy.
3. Enter the price per item.
4. Enter the quantity.
5. View your total.

Enter numbers only for the price and quantity. Use a whole number for the quantity.

## Requirements

- Java Development Kit (JDK) compatible with the project's `pom.xml`
- A Java IDE, such as IntelliJ IDEA

## Running the Program

Open `projects/shopping-cart` in IntelliJ IDEA, allow Maven to load, and run `Main.java`.

## Sample Output

```text
Item: apples
Quantity: 3
Your total is $4.5
```

This example uses a price of 1.50 per item.
